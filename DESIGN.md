- Основной акцент — **один** (`--clr-accent`). `--clr-accent2` используется только для смысловой подсветки результата/успеха (напр. `.result`, кнопка «Отправлено»).

- Никаких «сырых» hex/rgba вне `:root` в новых правках. Существующие инлайн-значения — мигрировать (см. Accepted debt).

### 1.3 Отступы и сетка

- Базовая единица: **4px** (все отступы кратны 4).
- Контейнер: `.container` — max-width ≈ 1200px, авто-поля.
- Секции: вертикальные отступы симметричные (существующая практика; в новых секциях — нижний чуть больше верхнего).

### 1.4 Радиусы (шкала)

| Токен-уровень | Значение | Где |
|---|---|---|
| S (внутренние, мелкие) | `6–8px` | инпуты, чипы |
| M | `12–16px` | карточки, кнопки-карточки |
| L (контейнеры) | `20–24px` | glass-card, модалка |
| Pill | `24–30px` | основные кнопки, badge |
| Circle | `50%` | иконки-кнопки (theme-toggle) |

Новые правки: использовать только эти уровни. НЕ вводить значения вне шкалы (5, 10px — мигрировать).

### 1.5 Тени и глубина

- Карточки: `box-shadow: 0 8px 32px rgba(0,0,0,.3)` + `inset 0 1px 0 rgba(255,255,255,.05)` (dark) — «стекло».
- Кнопки hover: `0 8px 30px rgba(0,0,0,.08)`.
- Светлая тема: тонированные тени без чёрного на 30% (см. styles.css `[data-theme="light"]`).
- Материал: **стекло** (glassmorphism) — `backdrop-filter: blur(20px) saturate(180%)` + 1px border + inset-свет.

## 3. Состояния

- **Hover**: кнопки `translateY(-2px)` + тень; карточки `translateY(-4px)` + border-акцент; ссылки — смена цвета.
- **Active/pressed**: `scale(0.98)`-эффект — рекомендуется добавить (сейчас нет).
- **Focus**: СЕЙЧАС только `.modal-form input:focus` — **пробел**. Новые правки обязаны добавлять `:focus-visible` (2px ring акцентного цвета) для всех интерактивных элементов.
- **Активный пункт меню**: класс `.nav-active` (underline) + `aria-current="page"` (добавляется).

## 4. Motion

- `reveal`: opacity + translateY(30px), 0.7s cubic-bezier(.22,1,.36,1), через IntersectionObserver → `.visible`.
- `rotateSlow`: hero SVG, 60s linear, GPU (transform).
- Прелоадер: assembly-анимация 0.9s spring-like (cubic-bezier(.34,1.56,.64,1)) — только transform/opacity.
- **Все анимации — только `transform`/`opacity`/`filter`.** Layout-свойства не анимировать.
- `@media (prefers-reduced-motion: reduce)`: отключать reveal/rotateSlow (прелоадер — по решению владельца остаётся).

## 5. A11y-констрейнты

- `lang="ru"` на всех страницах; один H1 на страницу (кроме calculator — фиксится).
- Skip-link + `<main>` — добавляется (P1).
- Мобильное меню: `aria-expanded` на бургере, Escape-закрытие, возврат фокуса (P2).
- Формы: label↔input связь (for/id), пояснение про mailto у кнопки отправки.
- Контраст: светлая/тёмная темы — проверить WCAG AA для muted-текста (`.82rem` на `--clr-bg`).

## 6. Accepted debt (зафиксировано, мигрировать постепенно)

1. **Дубликат критического CSS**: инлайн `<style>` в head index.html дублировал styles.css — **удаляется** (P1.2). styles.css — единый источник.
2. **Инлайн `style=""` на главной** (35 шт., padding/text-align вариации) — заменить utility-классами (P3.1).
3. **Две копии styles.css**: `/tools/styles.css` (23 КБ, дивергентна) — убрать из подключений, удалить файл (P2.5).
4. **Три версии nav.js** (root / tools/ / industries/) — оставить только корневую, копии удалить.
5. `footer.js` — используется только в `docs/*` (архивная зона, вне продакшн-дерева axiiom.ru) — оставить как есть, из продакшена не подключать.
6. Прелоадер без `prefers-reduced-motion` — осознанное решение владельца.
7. `border-radius: 5px/10px` — вне шкалы, мигрировать при касании файлов.
8. Шрифт Inter — оставить (бренд), при желании апгрейда — замена одним токеном в `--font-sans`.
9. Формы отправляются через `mailto:` (нет бэкенда) — осознанно, подпись у кнопки обязательна.
10. `webvisor:true` в Яндекс.Метрике — отключить (P3.6, приватность).

## 7. Правила внесения изменений
