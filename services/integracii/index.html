      Что решаем

      Где обычно рвётся

      Менеджер вручную переносит заказы из сайта в 1С

      Решение: автоматическая выгрузка по событиям. Человек не трогает данные — значит, не ошибается.

      Сверка платежей занимает полдня каждую пятницу

      Решение: оплата, заказ и учёт сходятся автоматически. Расхождения подсвечиваются, а не ищутся глазами.

      Два подрядчика делают по половине и не стыкуются

      Решение: берём стык на себя: контракты, тесты, обработка ошибок. Кто-то должен отвечать за шов.

      API поставщика меняется без предупреждения

      Решение: слой адаптеров и алерты на изменение контракта. Падает одна интеграция — не весь бизнес.

      Вопросы

      Частые вопросы

      Сколько стоит интеграция?

      Ориентир — от 300 000 ₽ за одну пару систем. Двусторонний обмен с очередями и мониторингом — дороже. Считаем по системам, а не «за проект целиком».

      Сколько времени?

      Простая односторонняя выгрузка — 2–3 недели. Двусторонний обмен с надёжностью — 4–8 недель, в зависимости от готовности API на стороне контрагента.

      У нас старый API, документации почти нет

      Обычная ситуация. Разбираем по логам и трафику, пишем документацию сами. Это время, но решаемо.

      Нужно ли менять наши системы?

      Нет, чаще всего не нужно. Интеграция как раз для случая, когда системы менять не хочется или нельзя.

      Кто отвечает, если API поставщика изменится?

      Мы, если есть поддержка по договору. Без неё — вы получите алерт и описание, что сломалось.

      Можно увидеть, как вы работаете с API?

      Да. Mock Services открыт на GitHub под Apache-2.0: там реальные протоколы Сбера, Альфы, Т-Банка, ЮKassa и АТОЛ.
