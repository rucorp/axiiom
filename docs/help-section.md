# Раздел «Помощь малому и микробизнесу» — как устроен и как менять

Раздел живёт по адресу **[/help/](https://axiiom.ru/help/)** и состоит из четырёх страниц
плюс трёх статей в блоге. Материал собран из `docs/small-business-help/`
(ветка `feat/small-business-help-sources`) — это источник фактов, а не публикуемый контент.

```
/help/
├── index.html               — хаб: когда нужно, три формата, процесс, цифры, FAQ
├── diagnostika/index.html   — диагностика и аудит, 2–3 недели
├── cto/index.html           — внешний технический директор (fractional CTO)
└── ai-transformaciya/index.html — ИИ-трансформация за 90 дней

/blog/vneshniy-cto-malyy-biznes/
/blog/diagnostika-tehdolga/
/blog/ai-transformaciya-90-dney/
```

## Правила, по которым написан текст

1. **Цифры — только из `MASTER.md`.** Ничего не додумано: 22 года в IT, 8 лет в роли CTO,
   команда 5 → 45, 45+ инженеров и руководителей, 830 100+ клиентов и 20 800+ торговых точек,
   выручка 166,3 млн ₽ и прибыль 19,9 млн ₽ за 2025, 149 репозиториев, 59 скиллов, 108 файлов
   учебника, 3× проектное финансирование Сбера 2,8–4,1 млрд ₽.
2. **Оценки помечены.** Оборот баллов «свыше 5 млрд ₽ в год» на страницах сопровождается
   оговоркой «оценка, отчётностью не подтверждена».
3. **Голос — от лица компании.** Никаких «я сделал», «мой exit»: «команда построила»,
   «AXIIOM выстраивал». ФИО владельца не публикуется (решение 07.11.2026).
4. **Цены не публикуются.** Формулировка одна: «фиксированная стоимость по договору,
   фиксированный результат», «помесячный ретейнер», «оплата по вехам».
5. **Не перенесено:** зарплата, состав PMOS, название платформы лояльности и её оператора,
   банк в проекте АБС/ДБО, фотокнига и упаковка, ВШЭ Giving Day, блоки 12–13 мастера.

## Как добавить новую страницу раздела

1. Создать `help/<слаг>/index.html` по образцу существующих: DOCTYPE, `lang="ru"`,
   `theme-color`, canonical на свой URL, OG + Twitter, JSON-LD (`WebPage` + `BreadcrumbList`
   + `Service` + `FAQPage`), `styles.css`, `preloader.css`, `navOverlay`/`mobileNav`,
   `header`/`footer`, `footerCopy`, `Nav.init({})`, `/metrika.js`, `gtag`, класс `help-hero`.
2. Добавить пункт в `TREE` в `nav.src.js` (в разделе `name: 'Малому бизнесу'`).
3. `python3 build.py` — пересоберёт `nav.js` и `styles.css`, обновит `?v=`.
4. `python3 generate_sitemap.py`.
5. Добавить OG-картинку в список `PAGES` в `generate_og_help.py` и запустить его
   (нужен `pillow`).
6. `python3 test_seo.py && python3 test_site.py --exit-code`.

## Открытые вопросы (нужно решение владельца)

- **Цены.** Сейчас на страницах намеренно нет цифр. Если решите показать вилку
  диагностики — правится в hero-бейджах и в блоке «Форматы».
- **`/help/` в калькуляторе.** Калькулятор считает проекты разработки; для аудита и
  ретейнера нужна отдельная логика — пока ссылка ведёт на общую форму.
- **ФИО и фото.** Страницы написаны от лица компании. Если решите добавить авторство
  (фото + «Сергей Кузюков, основатель AXIIOM») — это блок `author-block`, он уже есть
  в отраслевых страницах.

## Типографика списков блока «Границы роли» (13.11.2026, issue #26)

Списки в блоке `.help-scope` («делаю / не делаю») свёрстаны grid-колонкой:
`li { display:grid; grid-template-columns:auto 1fr; gap:10px; align-items:baseline }`,
маркер `::before` — `'—' / ''` (тихий для скринридеров) в первой колонке, `position:static`.
На контейнере `.help-scope` задан `text-align:left` — сброс наследованного от `.section`
центрирования. У каждого `<ul>` внутри `.help-scope` должен стоять `role="list"`
(иначе Safari/VoiceOver теряет семантику списка при `list-style:none`). При переносе
длинной строки текст идёт строго по границе колонки, не под маркер. Цвета и кегль
(`--clr-faint`, `.9rem`, line-height 1.6) не менялись.

## Долг

- `.help-card ul li::before` на `help/index.html` — тот же механизм центрирования

  сообщался, в радиус #26 не входил. Фикс отдельной задачей при появлении симптома.
