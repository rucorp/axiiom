05. Приватный контур на аренде (managed private)
Статус доступно
Поставка выделенный шард на нашей инфраструктуре, до 280 000 минут в месяц
Зависимости 07-deployment.md, 02-architecture.md §6

Проблема

Между «облако» и «коробка on-prem» нет нормального варианта среднего размера.

  • Облако не подходит, когда служба безопасности говорит: «записи разговоров с клиентами не должны лежать на чужой инфраструктуре» (банки, медицина, коллекшн, госсектор).
  • Коробка требует железа и ЦОД заказчика, 4–8 недель внедрения и собственных админов. Для компании со 100–500 операторами это слишком тяжело.

Решение

Выделенный шард на нашей арендованной инфраструктуре. Заказчик получает изоляцию уровня «свой контур» без покупки железа, без лицензионного платежа и без админов:

Свойство Как реализуется
Изоляция вычислений отдельный namespace/кластер, отдельные GPU-пулы по расписанию, никакого мультитенантного шаринга процессов
Изоляция данных отдельный S3-бакет и отдельная БД; ключи шифрования — свои, по запросу — в KMS заказчика (BYOK)
Сеть возможен приватный канал (VPN/peering) из контура заказчика; публичный API — по желанию
Обновления окна обновлений согласуются; откат до предыдущей версии модели — по регламенту
Мониторинг SLA 99,5 %, 24/7, реакция 4 раб. часа (критично — 1 час)
Переезд в любой момент можно перейти в коробку: выгружаем дампы и передаём по акту, без потери разметки и версий таксономии

Важно, что остаётся общим: логика поставки, API, карточка звонка, конструктор таксономии и обновления моделей. Клиент не «застревает» в отдельной ветке продукта.

Как это выглядит

  • Экран «Контур»: статус изоляции, использованные минуты, окно обновлений, ответственный инженер.
  • Комплаенс-пакет для службы безопасности: схема потоков данных, перечень хранения, документ «где лежат ПДн», инструкция по уничтожению данных по требованию субъекта ПД.
  • API/вебхуки — те же, что в облаке (08-api.md).

Метрики успеха

Метрика Цель
Развёртывание нового шарда ≤ 5 рабочих дней (для сравнения: коробка — 4–8 недель)
Прохождение проверки ИБ заказчика с первого раза ≥ 70 %
Изоляция: результаты теста на кросс-доступ (мы делаем сами и отдаём отчёт) 0 инцидентов
Конверсия «Приватного контура» в коробку за 2 года ≤ 15 % (значит, не переплачивают)

Как это устроено у нас

  • Выделенный шард: свои ключи шифрования (BYOK), изолированные вычисления и хранилище в РФ.
  • Приватный сетевой канал и отдельный контур доступа к транскриптам.
  • Переезд в on-prem без потери разметки: та же кодовая база и те же данные.
