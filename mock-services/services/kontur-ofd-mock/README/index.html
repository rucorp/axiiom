kontur-ofd-mock — Контур.ОФД, read/reconciliation ​

Девятый сервис стенда, касса/ОФД №4, issue #97. Только чтение уже фискализированных документов: это не очередь печати, не Ferma и не OKassa. Node ≥18, CommonJS, zero dependencies, общее ядро packages/core не изменено.

Источник (2026-10-11): официальная документация Контур.ОФД (auth/access, документы). Рецепт интеграции, curl, сценарии и полный список [FORK], OpenAPI, drift-манифест.

Запуск ​

bash
# Сначала задайте синтетические env по рецепту интеграции (см. ссылку выше).
npm run start:kontur-ofd    # :3108
npm run test:kontur-ofd     # HTTP selftest на :0, без Docker

Дефолтных login/password/API key нет. Без env default-auth закрыт; в owned-песочнице реквизиты генерируются при POST /sandboxes. Это [FORK]: публичных статических тестовых кредов провайдера нет, выданные ему реквизиты не коммитить и не использовать на mock-стенде.

Docker: docker build -t mock-services:kontur-local ., затем MOCK_IMAGE=mock-services MOCK_IMAGE_TAG=kontur-local MOCK_IMAGE_DIGEST='' docker compose -f docker-compose.include.yml --profile mock up -d kontur-ofd-mock. Старый pinned GHCR-релиз 0.6.0 не содержит новый сервис; образ и pin публикует владелец отдельно. Корневой docker-compose.yml намеренно не меняется.

Все /v2/... требуют Authorization: auth.sid <Sid> иX-Kontur-Ofd-ApiKey. Sid живёт 30 дней на виртуальных часах; при отсутствии, истечении/отзыве → 401 errorCodeId=401002. Пропущенный/неизвестный ключ → 401 401003. При ошибках ориентироваться на errorCodeId, не на устаревшее errorCode. Неправильные даты/параметры: 400; нет согласия: 403; неизвестный объект: 404; fail: 500. Пустой период → 200, пустой список.

Документы: все 10 типов из среза; суммы в целых копейках; в receipt items, operationType, fiscalDocumentNumber, fiscalSign, id. Демо-каталог каждой песочницы: org-demo, касса 0000000000000001, 12 ФД за 2026-10-11, включая три receipt, один из них возврат. Демо не меняется от виртуального времени. Фикстуры синтетические, имена неполностью раскрытых полей и FFD-операции — [FORK].

[FORK] offset/currentOffset: каноничен offset, currentOffset даёт 400 с подсказкой; nextOffset=null завершает обход. Выбор согласован с владельцем до кода по URL-примерам и подтверждён локальной OpenAPI/selftest; подтверждение тестовой схемой провайдера не получено. Предел страницы — 1000. UTC без timezone и включённые обе границы периода — [FORK].

В owned запросах добавляйте X-Mock-Sandbox + X-Sandbox-Token наряду сAuthorization: auth.sid ... и API key. Чужие токены и знание ID не дают прав. Control token в hosted обязателен; оператор может управлять песочницами, владелец — только своей. Reset/state import/rotation отзывают Sid; экспорт /mock/state не раскрывает Sid, /sandboxes/me не раскрывает креды. Persist files содержат mock-сессии/креды; защищайте volume и не храните реальные чеки/ПДн. Модель угроз.

Сценарии и ограничения ​

X-Mock-Scenario: fail|hang|duplicate|latency:200ms|http-500|http-504. В POST /mock/scenarios доступны target: auth|read|*, times, persistent, match; сценарии и журнал изолированы по песочницам. duplicate повторяет тот же ФД перед пагинацией, не создаёт чек. hang завершается закрытием соединения клиентом. Виртуальное время двигается POST /mock/time.

Не моделируется: создание/фискализация чека, запуск возврата, callback печати, очередь статусов, Cookie auth.sid, статистика, сложная история согласий и фильтрация по их периодам. Объединение двух удалённых hosts в один локальный сервис, numeric cursor/null, fixture-envelope, UTC, повторные Sid, error messages и сценарии — явно документированные [FORK], не гарантия провайдера. Проверка реального тестового контура/закрытой схемы не выполнена.

Байтовые квоты состояния (PD-02) ​

EnvДефолтНазначение
MOCK_SANDBOX_MAX_STATE_BYTESпусто: 8388608 (8 МиБ) при maxDocuments > 0, иначе без лимитабайты JSON одной песочницы; 0 выключает
MOCK_SANDBOX_GLOBAL_MAX_STATE_BYTES67108864 (64 МиБ)сумма байт JSON всех песочниц рантайма, включая default; 0 выключает

Значения задаются в целых байтах. Пусто сохраняет дефолты. Квота per-sandbox не ограничивает память контейнера; общий бюджет меньше mem_limit: 128m, но не равен RSS. Превышение глобального бюджета на записи или байтовых квот при импорте /mock/state → HTTP 400, errorCode: 400, kind: 'bytes', code: sandbox_state_budget_exceeded / sandbox_state_quota_exceeded, с откатом отклонённого состояния. Правила/история/журнал остаются volatile. Подробности и границы — документация ядра.
